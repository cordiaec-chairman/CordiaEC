02

번역 기능 완벽 정리: 상단 [번역하기] vs 기본 [저장 시 자동 번역]

상단 버튼은 '수동 즉시 확인용'이고, 자동번역은 '디폴트로 켜두면 알아서 해주는 기능'입니다.

💡 핵심 정의: 상단에 있는 버튼은 자동번역이 아니라 [번역하기] 버튼(직접 보고 고치는 용도)이고, [자동 번역]은 말 그대로 관리자님이 신경 안 써도 디폴트를 자동으로 해두면 저장할 때 알아서 번역해주는 기능입니다.
버튼 ① 상단 탭 옆 [✨ 번역하기] 수동 즉시 번역 (미리보기·수정용)

"영어로 어떻게 번역되는지 지금 바로 확인하고 고치고 싶을 때"

국문을 작성하다가 이 버튼을 누르면, 그 즉시 영문 탭으로 번역본이 채워집니다. 영문 탭으로 이동해 번역된 문장을 눈으로 직접 검토하고, 특정 단어나 문구를 직접 교정·수정하고 싶을 때 사용합니다.

👉 추천 상황: 중요한 공식 성명이나 영문 표현을 사전에 꼼꼼히 확인하고 교정하고 싶을 때
기본 옵션 ② 우측/하단 [저장 시 자동 번역] (기본 켜짐) 전자동 백그라운드 번역 (신경 쓸 필요 없음)

"내가 신경 안 써도 디폴트로 켜두면 알아서 번역해서 저장해라"

영문 탭을 굳이 열어보실 필요가 전혀 없습니다. 한국어로만 글을 작성하고 하단 [저장] 버튼만 누르면, 시스템이 DeepL 번역을 알아서 수행하여 국문·영문 양쪽 버전을 동시에 완성해 웹사이트에 배포합니다.

👉 추천 상황: 바쁜 일상 업무 중 한국어 기사만 빠르게 등록하고 곧바로 업무를 마치고 싶을 때 (가장 추천하는 모드)
✨ 관리자님을 위한 맞춤 요약: "복잡하게 영문 확인 안 하고 빠르고 편하게 올리겠다"면 상단 [번역하기] 버튼은 건드릴 필요 없이, 국문만 작성하고 하단 [저장]만 누르시면 시스템이 영문 번역까지 알아서 완벽하게 처리해 드립니다!
03

글 작성 화면 필드별 상세 안내: "여기엔 뭘 넣어야 하나요?"

글 작성 창은 좌측(본문 콘텐츠 작성)과 우측(게시 및 파일 설정)의 2개 열로 구성되어 있습니다.

게시글 작성 화면 영역 매핑도 모달 2단 분할 구조
[좌측] 본문 콘텐츠 캔버스 글 내용 작성 중심
❶ [국문 작성] / [영문 작성] 탭 기본은 국문 작성 선택
❷ 제목 (국문) *
메인 카드 및 기사 상단에 표시될 굵은 헤드라인 (30~50자 권장)
❸ 요약문 (국문)
목록 카드 아래에 미리보기로 노출되는 1~2줄 핵심 요약 (80~120자 권장)
❹ 서식 툴바 & ❺ 상세 본문 (국문) Ctrl+V 이미지 붙여넣기 지원

[우측] 게시 및 미디어 설정 카테고리 & 파일 첨부

❿ 하단 옵션: [✨ 저장 시 자동 번역] 토글 (켜두면 원클릭 영문 자동 생성)

예: 양민아 연구교수, 미국 풀브라이트 협회 '셀마 진 코헨 무용 강연상' 수상 		30~50자 내외로 핵심 사실을 명확하게 적으면 카드에서 가장 예쁩니다.

예: 중앙아시아연구소 양민아 연구교수가 한국 소재 연구자 최초로 무용학 분야 최고 권위상을 수상했습니다. 		생략하면 본문 앞부분이 자동 노출되지만, 1~2줄 요약을 직접 적으면 웹사이트가 훨씬 전문적으로 보입니다.
❹ 서식 툴바 도구 소제목(H2, H3), 볼드체(B), 이탤릭(I), 인용문, 글머리 기호(•), 번호 목록, 구분선(---), 본문 사진 삽입 버튼 소제목을 중간중간 넣어주면 긴 글도 방문자가 읽기 편합니다.

04

추천 작성 순서: 실패 없는 5단계 프로세스

실무에서 가장 빠르고 실수 없이 글을 발행하는 추천 순서입니다.

STEP 1
기본 설정 확인

우측 영역에서 [게시판 구분](뉴스/칼럼/보고서)과 [발행일자]를 먼저 확인합니다.

우측 상단 ❻, ❼번
STEP 2
제목 & 요약 작성

좌측 상단에서 [제목]과 메인 홈 카드에 보일 1~2줄 [요약문]을 한국어로 적습니다.

좌측 상단 ❷, ❸번
STEP 3
상세 본문 작성

기사 전문을 작성합니다. 캡처한 이미지가 있다면 본문에서 바로 Ctrl+V로 붙여넣습니다.

좌측 캔버스 ❹, ❺번
STEP 4
사진 / PDF 첨부

우측 영역에서 메인 카드에 보일 [대표 썸네일]을 올리고, 리포트라면 [PDF]를 첨부합니다.

우측 하단 ❿, ⓫번
STEP 5
[저장] 클릭 완료!

영문 탭 갈 필요 없이 하단 [저장] 누른 후 [자동 번역 후 저장]만 확인하면 한/영 동시 발행 완료!

05

유튜브 영상 순서 정렬 & 드래그 앤 드롭 가이드

홈 화면 미디어 쇼케이스에 어떤 영상을 대표(1위)로 띄울지 마우스 드래그와 버튼으로 자유롭게 통제합니다.

기능 1

정렬 기준 3종 원클릭 전환

상단 툴바에서 [지정 순서], [최신순], [인기/대표순] 버튼을 눌러 원하는 기준으로 영상 목록을 즉시 정렬할 수 있습니다.

기능 2

마우스 드래그 앤 드롭 (순서 이동)

카드 좌측의 핸들(⋮⋮)을 잡고 원하는 위치로 끌어다 놓으면(Drop), 1위부터 번호가 자동 재부여되며 홈 화면에 즉시 순서가 실시간 저장됩니다. (▲/▼ 화살표 버튼으로 1칸씩 이동도 가능)

기능 3

숫자 직접 입력 & 일괄 저장

기존처럼 영상 수정 창에서 [노출 순서] 숫자를 직접 타이핑해 지정할 수도 있으며, [현재 정렬대로 순서번호 일괄 저장] 버튼을 누르면 전체 영상 번호가 1초 만에 깔끔하게 재정리됩니다.

06

번역 고정 용어집(Glossary) 완벽 활용 가이드

고유명사, 기관명, 연구소명, 인명이 영어로 이상하게 오역되는 문제를 100% 원천 차단합니다.

📖 왜 고정 용어집을 써야 할까요?

일반 AI 번역기는 K-학술확산연구센터를 매번 임의로 번역하지만, 용어집에 등록해 두면 시스템이 항상 지정된 공식 영문 명칭(예: K-Academic Diffusion Research Center)으로 100% 고정하여 번역합니다.

등록 방법 A
[번역 고정 용어집] 탭에서 직접 추가

좌측 사이드바 [번역 고정 용어집] 메뉴 클릭 ➔ [새 용어 등록] ➔ 한국어 단어와 지정할 영어 단어를 한 쌍으로 입력하고 저장합니다.

등록 방법 B (가장 빠름)
본문 쓰다가 마우스 우클릭으로 원클릭 등록

게시글 본문을 작성하다가 고정하고 싶은 단어를 마우스로 쓱 드래그한 후 우클릭하면 용어집 팝오버가 뜹니다. 그 자리에서 영단어를 넣고 바로 등록할 수 있습니다!

✨
실시간 반영 원리: 용어집에 등록된 단어들은 관리자님이 상단 [번역하기]를 누르거나 기본 [저장 시 자동 번역]으로 저장할 때마다 DeepL AI에 사전 규칙으로 강제 주입되어 영구적으로 일관된 번역 품질을 유지합니다.
